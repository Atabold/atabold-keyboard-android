# Security policy

This repository holds the Android app of Atabold Keyboard. The security policy for the whole project is in the main repository:

**<https://github.com/Atabold/atabold-keyboard/blob/main/SECURITY.md>**

To report a vulnerability in the app **privately**, use *Security → Report a vulnerability* on this repository (GitHub private vulnerability reporting). Please do not open a public issue for it.

Bugs in code that comes from FUTO Keyboard and that this fork did not change belong to [FUTO](https://github.com/futo-org/android-keyboard). If you are not sure, report it here and it will be sorted out.
